03

jingle

Rust · Apache 2.0 · Kowo

A password manager for AI agents, built so the agent never sees a password. Secrets leave through exactly four doors: injected into a child process, onto the clipboard for thirty seconds, as a TOTP code, or an explicit print you have to ask for. Every other command returns REDACTED, and the audit log hash-chains each line to the one before it.

$ jingle add github --generate --length 32 Created 'github' (password set, 205 bits) $ jingle exec -s github=GH_PASS -- ./signup.sh $ jingle show github password: [REDACTED]
