Work

Typer Swift · MIT · alpha

On-device autocomplete for macOS. A faint suggestion appears at your caret in almost any text field and streams in word by word. It runs against a small GGUF model through llama.cpp, so there is no cloud, no account, and nothing leaves the Mac.

typr.frgmt.xyz

Beckett TypeScript · MIT

A Discord-native AI engineer. You mention it, it judges how much effort the request deserves, and for real work it opens a numbered task and hands the branches to a pool of coding agents running in isolated worktrees. One agent does the talking. The rest do the building.

Built at Kowo Research, and built to be forked.

Jingle Rust · Apache 2.0

A password manager for AI agents that never shows the agent a password. Secrets leave through four doors: a child process environment, the clipboard for thirty seconds, a TOTP code, or a print you have to ask for by name. Everything else returns REDACTED, and each audit line carries the hash of the one before it.

Built at Kowo Research.
